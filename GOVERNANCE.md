# Zolto Project Governance

## Versioning Policy
Zolto strictly follows Semantic Versioning (SemVer) 2.0.0.
- **Major (1.x.x)**: Incompatible API or Language changes.
- **Minor (x.1.x)**: Backward-compatible functionality additions.
- **Patch (x.x.1)**: Backward-compatible bug fixes.

## Release Schedule
- **Stable Releases**: Biannual (Every 6 months).
- **Patch Releases**: As needed for critical bugs or security fixes.
- **Release Candidates (RC)**: Shipped 4 weeks prior to a Stable release.

## Roles & Responsibilities
- **Core Maintainers**: Hold commit access and manage the release cycle.
- **Contributors**: Submit patches, report bugs, and propose features.
